CHOUPO Open Source Chemical Process Simulator

The process simulator that shows its work.

Design a process with your own AI assistant; Choupo computes it and shows every number, so you can judge it.

Choupo is a free and open-source chemical process simulator: chemical engineering flowsheet simulation software for steady-state and dynamic processes, written in C++17 and run in your browser through WebAssembly, with nothing to install. Build steady, batch and controlled processes; inspect thermodynamics; fit property models; and follow the balances and nonlinear solves all the way to the answer — flash and phase equilibrium, MESH distillation, CSTR, PFR and Gibbs reactors, heat exchangers, compressors, reverse-osmosis and nanofiltration membranes, electrodialysis, crystallisation and drying.

Understand why engineering correlations stay simple.

What is exergy?

See why the same heat buys different work at different temperatures.

That energy is conserved but the capacity to produce work is not: the same heat from two reservoirs, B_Q = Q(1 - T0/T), buys different work. There is no published native .exe installer. The Unix commands below run inside WSL2 (Ubuntu), not in PowerShell or CMD.

# In PowerShell (admin), then reboot:
wsl --install -d Ubuntu

# Inside the Ubuntu (WSL2) shell:
sudo apt update && sudo apt install -y git build-essential
git clone https://github.com/choupo-admin/choupo.git
cd choupo
make all

source etc/bashrc
runCase tutorials/steady/flash/flash01_benzene_toluene
bin/runTests

# The graphical interface (GUI), once:
sudo apt install -y nodejs npm emscripten
make wasm-gui
# then bin/runGui, and open in Windows:
#   http://127.0.0.1:5173/
bin/runGui

Linux

The native target. Only a C++17 compiler and GNU make are required — zero external libraries.

The graphical interface on your own computer needs three more tools — Node.js, npm and Emscripten — because it runs the engine compiled to WebAssembly. bin/runGui checks each one, says in one sentence what is missing, and opens a browser window at http://127.0.0.1:5173/. After pulling a new version, run make wasm-gui again.

Read the full build guide

# Debian / Ubuntu deps:
sudo apt install -y git build-essential

git clone https://github.com/choupo-admin/choupo.git
cd choupo
make all

source etc/bashrc
runCase tutorials/steady/flash/flash01_benzene_toluene
bin/runTests

# The graphical interface (GUI), once:
sudo apt install -y nodejs npm emscripten
make wasm-gui
# then, every time:
bin/runGui
bin/runGui --kill        # stops it

iPhone & iPad

The browser app runs in Safari and can be added to the Home Screen (Share → Add to Home Screen) to open full-screen.

Reading cases, running tutorials and inspecting results work on iPad. Building or editing flowsheets is not recommended on small phone screens.

There is no native iOS app. Choupo on iPhone and iPad means the WebAssembly build in Safari — the same engine, in the browser.
